# 11. 인스타 릴스 발행 엔드포인트 (`publish-reel`) 레퍼런스

> 작성일: 2026-06-13 · 이 문서는 **`/instagram/publish-reel` 엔드포인트 자체의 설명서**다(드라이브 영상 1개 → 채널 IG 릴스).
> 이 엔드포인트를 **자동·일괄로 호출하는 운영 워크플로우**(영상시트→미발행분 일괄 크로스포스트)는 `12_쇼츠커머스_큐레이션발행_자동화.md`의 `WF-쇼츠 IG 크로스포스트` 참고. 본 문서는 엔드포인트 스펙 + 단발 호출 방법.
> 같은 엔드포인트가 **shortcrew(인플루언서)·short-mall(지식쇼츠) 양쪽에 포팅**돼 있다 — base 주소만 다르다.

## 구조 (로직은 코드, n8n은 1방 호출)
```
[펌프 영상 렌더 → Google Drive]   (기존, short-mall)
        │
        ├──→ (기존) 펌프 유튜브/인스타 발행          ← 그대로 둠
        │
        └──→ (신규) Drive 영상 공개링크 → HTTP 1번
                 POST /admin/api/ops/instagram/publish-reel
                 = shortcrew 인플루언서 IG 계정에 릴스 발행
```
인스타 릴스는 `컨테이너 생성 → 인코딩 폴링 → 발행` 3단계인데, **세 단계 전부 FastAPI 엔드포인트가 처리**한다. n8n은 HTTP Request 노드 1개면 끝(폴링 루프 불필요).

## 엔드포인트
- 인플루언서(세련·세림·소율): `POST https://shortcrew.co.kr/admin/api/ops/instagram/publish-reel`
- 지식쇼츠(홈캠카오스 등 05/09/10/11/33): `POST https://short-mall.com/admin/api/ops/instagram/publish-reel` (동일 코드 포팅, IG 토큰은 short-mall .env)

- 인증: 헤더 `X-Ops-Token: <OPS_API_TOKEN>` (어드민 쿠키 아님 — n8n용 공유 토큰). `.env` 의 `OPS_API_TOKEN`.
- 코드: [app/admin/ops/routes/instagram_publish.py](../app/admin/ops/routes/instagram_publish.py). 계정/토큰은 dm.py 와 동일하게 `CHANNEL_{ID}_IG_*` env 직접 읽음.

요청 본문(JSON):
```json
{
  "channel_id": "02",
  "video_url": "https://drive.google.com/uc?export=download&id=<DRIVE_FILE_ID>",
  "caption": "골프팁 ... #골프 #오세련픽 #shorts",
  "share_to_feed": true,
  "dry_run": false
}
```
- `channel_id`: 02 = 오세련픽(seryeon.golf). 03=왕세림픽(테니스), 04=한소율픽(쇼핑).
- `video_url`: **공개 접근 가능한 영상 직링크**(인스타 서버가 직접 받아감). 드라이브 파일은 "링크가 있는 모든 사용자" 공개 후 `uc?export=download&id=` 형식.
- `dry_run: true` → 네트워크 호출 없이 보낼 요청만 echo(연결 점검용).

응답:
```json
{ "ok": true, "channel_id": "02", "creation_id": "...", "media_id": "...", "permalink": "https://www.instagram.com/reel/..." }
```

## 채널 IG 계정 등록 (.env)
채널 추가 시 4줄을 채널번호만 바꿔 반복. user_id 는 토큰으로 조회:
```
curl "https://graph.instagram.com/me?fields=user_id,username,account_type&access_token=<TOKEN>"
```
```
CHANNEL_02_IG_USERNAME=seryeon.golf
CHANNEL_02_IG_ACCOUNT_ID=<user_id>          # 발행 경로 /{id}/media 에 사용
CHANNEL_02_IG_APP_SCOPED_ID=<id>
CHANNEL_02_IG_ACCESS_TOKEN=<long-lived token>
```

## n8n 노드 구성 (펌프 영상 WF 끝, 유튜브 업로드 다음에 분기)
1. **Google Drive — Share** : 발행할 영상 파일을 `anyone / reader` 로 공개.
   - File: 직전 단계의 드라이브 fileId.
2. **Set (또는 Code)** : 공개 직링크 생성.
   - `video_url = https://drive.google.com/uc?export=download&id={{ $json.fileId }}`
3. **HTTP Request** :
   - Method: `POST`
   - URL: `https://shortcrew.co.kr/admin/api/ops/instagram/publish-reel`
   - Headers: `X-Ops-Token: <OPS_API_TOKEN>` , `Content-Type: application/json`
   - Body(JSON): `{ "channel_id": "02", "video_url": "{{ $json.video_url }}", "caption": "{{ $json.caption }}" }`
   - **Timeout: 240000ms** (엔드포인트가 인코딩 끝까지 최대 ~3분 폴링 후 발행).

> 큰 영상(>~100MB)은 드라이브 `uc?export=download` 가 바이러스검사 안내 HTML을 줄 수 있다. 릴스는 짧아 보통 문제없지만, 안되면 영상을 공개 정적 경로(예: shortcrew static/cloudflare)로 올려 그 URL을 쓴다.

## 테스트 순서
1. `dry_run:true` 로 1방 → 200 + create_url 확인(토큰·채널 연결 점검).
2. 짧은 실제 영상 1개로 `dry_run:false` → IG 릴스 게시 확인, permalink 회수.
3. 펌프 WF에 노드 연결 → 자동 크로스포스트.

## 주의
- `OPS_API_TOKEN` 비우면 엔드포인트는 503(잠금). 커밋 금지(.env).
- 공개 URL(`/admin/...`)이지만 어드민 쿠키가 아니라 토큰으로만 열린다 — 토큰 유출 주의.
- IG 토큰은 **40일 주기 자동갱신 스케줄러**가 갱신(만료 근절) → 수동 교체 불필요. 갱신 실패 시에만 발행 502 → `CHANNEL_02_IG_ACCESS_TOKEN` 점검.
