# 05 — 클라이언트(공개) UI · ShortCrew V2.0

> 구 `05_CLIENT_UI_OVERHAUL.md`(요약)와 `08_CLIENT_UI_REBRAND.md`(Phase 리브랜딩)를 **하나로 통합**한 문서.
> 리브랜딩은 **완료 상태**이며, 아래는 현행 공개 UI의 기준(테마·계약·검증)을 정리한 레퍼런스다.
> 기준 매뉴얼(PDF): [00_Manual_CLIENT_UI_Change.pdf](../00.통합자료실/참고자료/00_Manual_CLIENT_UI_Change.pdf)

## 목표 / 콘셉트

Short-on(퍼플·라이트)에서 **ShortCrew V2.0**(다크 차콜 / 시안 / 앰버)으로 전면 리브랜딩.

- 시각: **모바일 퍼스트** 팬덤·쇼핑 UX — **Pretendard**, 다크 차콜 `#121212`, 시안 `#00C2D1`, 앰버 CTA `#FFB800`, 슬림 스티키 헤더 **52px**, 홈 **2열 큐카드**, 상품 **2열·1:1** 썸네일, **5개/페이지**, 상품명 **검색**
- 기술: 단일 [static/css/style.css](../static/css/style.css) + [app/client/templates](../app/client/templates). per-mall 테마 엔진 [app/client/mall_theme.py](../app/client/mall_theme.py)
- 관리자: Tailwind + [_admin_tailwind_config.html](../app/admin/templates/_admin_tailwind_config.html) (시안 primary, 클라이언트와 색감 통일) — 상세는 [04_백오피스UI환경SQLite.md](04_백오피스UI환경SQLite.md)

## 불변 계약 (회귀 금지)

- [static/js/tracking.js](../static/js/tracking.js): `data-track-click`, `data-influencer`, `data-product-id` 트래킹 속성

## 트래킹·URL 규칙

1. **시트 상품:** `data-product-id` = VP/ctag 추출 문자열. `/api/click` 정수 파싱(DB id와 불일치 가능 — 레거시 유지)
2. **일기장 상세:** `buy_url` 서버 보강만. 상단 인라인 + 하단 fixed 도크 **동일 `data-*`**, CTA **amber**

## 상품 전시 순서 — 일일 랜덤화

- `/api/mall-products` 프록시 응답에서 시트 JSON을 **날짜 시드 셔플**: `random.Random(str(date.today())).shuffle(items)`
- 같은 날에는 모든 사용자에게 동일 순서, 자정(KST) 넘으면 자동 변경 — 별도 cron 불필요
- 캐시(TTL)에 셔플 결과를 저장하므로 캐시 히트 시에도 순서 일관
- 위치: [main.py](../main.py) `api_mall_products()` — 캐시 저장 직전 셔플

## 공개 URL

- `/{name_slug}`, `/{name_slug}/review`, `/{name_slug}/review/{id}`, `/{name_slug}/introduce`, `/`(홈), `/about`
- `/shop/…`, `/reviews/…` → **301**

## 검증 / 완료 기준 (DoD)

- 헤더·푸터·`main.page-body` 동일 `max-width` 1240px, `--page-pad-x`
- 다크 배경, 카드 그림자 없음, `shop-section-band` 8px 노출
- 모바일 ≤720px: 상품 2열·1:1·5개 페이징
- `mall_theme_json` 비움 → fallback 동작
- 레거시 301 3경로 동작
- `prefers-reduced-motion`: 마키 off
- admin primary 시안, JSON 편집 동작
- 트래킹 회귀 없음(`/api/click` POST: 상품·일기장 CTA)
- 자동 테스트: [tests/](../tests/) — 현재 [test_smoke.py](../tests/test_smoke.py)·[test_shorts_sheet_matcher.py](../tests/test_shorts_sheet_matcher.py) (테마 전용 테스트는 미작성)
