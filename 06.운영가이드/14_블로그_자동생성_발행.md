# 14. 몰 블로그 자동생성·발행 (구현)

## 개요
각 펌프 몰에 **블로그 탭**과 **개별 SEO 페이지**를 제공한다. 글은 Gemini 자동 생성이며
**상품 이미지 1개 필수**(텍스트만 글 금지), 성격은 **정보성 + 상품리뷰 혼합**, 글 마지막에
**연관 유튜브 영상 임베드**, 대표 상품이미지 1장으로 **인스타 발행(자동/수동)**.

## 데이터 (`blog_posts` 테이블, MySQL)
`models.BlogPost`: pump_slug, title, body_html, excerpt, **product_image_url(필수)**,
product_title, product_deeplink, thumbnail, youtube_url, source_topic, status(draft|published),
ig_media_id, ig_published_at, created_at.

## 공개 (몰)
- 블로그 탭: `GET /api/blog?slug={pump_slug}` → published 글 목록(모바일 퍼스트 리스트).
- 개별 SEO 페이지: `GET /{pump_slug}/blog/{id}` → `blog_detail.html`
  (상품이미지 상단 + 본문 + 구매버튼(nofollow sponsored) + **마지막 유튜브 임베드** + 파트너스 고지).

## 생성
- **자동**: 브리지 큐레이션 `POST /admin/api/ops/bridge/curate` 에 `auto_blog:true` →
  선정 상품마다 `blog_service.generate_blog_fields`(Gemini)로 글 생성 → `BlogPost(status=published)`.
  상품 이미지 없으면 그 글만 스킵.
- **수동**: `POST /admin/api/ops/blog/generate` (상품1개 지정; 이미지 필수; `auto_publish`/`auto_ig` 옵션).

## 관리 API (`X-Ops-Token`)
- `GET /admin/api/ops/blog/list?slug=` — 전체 상태 목록.
- `POST /admin/api/ops/blog/{id}/status` — published/draft 토글.
- `POST /admin/api/ops/blog/{id}/publish-ig` — **대표 상품이미지 1장 + 캡션 → 채널 IG 피드 발행**
  (자동/수동 공용; `dry_run` 지원). 성공 시 ig_media_id 저장·published.

## 인스타 발행 규칙
- 형식: **대표 상품이미지 1장 피드** + 캡션(제목·요약·구매링크·해시태그·파트너스 고지).
- 채널 IG 계정: `CHANNEL_{id}_IG_*`(00식). pump_slug→channel_id=`blog_service.channel_id_for_pump_slug`.

## 유튜브 임베드
- `blog_service.youtube_embed_html(url)`: shorts/watch/youtu.be → `/embed/{id}` 반응형 iframe.
- 소스: `blog_posts.youtube_url`(연관 쇼츠). 없으면 임베드 생략.

  재활용해 관리 페이지 배선 예정. 지금은 생성·관리·발행 **API 완비**(UI 미배선).
