# 13. 유튜브 영상 발행 + 연결 인스타 자동 업로드 (구조 설계)

> 상태: **구조 세팅(스캐폴드)**. 실제 배선·최종 n8n JSON 반영은 운영자 확인 후 진행.
> Salog(`n8n-sample/Salog/10-새록-쇼츠발행파이프라인.json`)의 S5 단계를 **참고만** 했으며 코드는 섞지 않았다.

## 목표
렌더 완료된 쇼츠 영상 1개를 **① YouTube 업로드 + ② 연결된 인스타 릴스 자동 업로드** 한다.

## 역할 분담 (핵심)
| 단계 | 담당 | 근거 |
|---|---|---|
| YouTube 업로드 | **n8n `youTube`(OAuth2) 노드** | 채널별 OAuth 크리덴셜은 n8n 이 보유. 서버는 토큰 없음 → 서버 구현 안 함 |
| 영상 공개 URL 확보 | n8n(Drive 업로드+공개권한) 또는 기존 영상 공개직링크 | IG 컨테이너는 공개 URL 필요 |
| **인스타 릴스 발행** | **shortcrew `POST /admin/api/ops/instagram/publish-reel`** (이미 구현) | 컨테이너 생성→인코딩 폴링→발행까지 1콜 |
| 결과 ingest(youtube_id/ig_media_id 시트기록) | n8n → 기존 시트/OPS | 선택 |

## 흐름 (Salog S5 대응 — 참고)
```
렌더영상(공개 직링크)
  ├─ [n8n youTube 노드] YouTube 업로드 → youtube_id
  └─ [n8n httpRequest] shortcrew /instagram/publish-reel
         body: { channel_id, video_url(공개직링크), caption, share_to_feed:true }
         → 서버가 IG 컨테이너 생성·인코딩 폴링·발행 → { media_id, permalink }
  └─ [n8n] 시트에 youtube_id·ig_media_id 기록(선택)
```

## shortcrew 측 (이미 존재 — 추가 구현 불필요)
- `app/admin/ops/routes/instagram_publish.py` → `POST /admin/api/ops/instagram/publish-reel`
  - 인증: `X-Ops-Token: $OPS_API_TOKEN`
  - IG 계정/토큰: `CHANNEL_{id}_IG_ACCOUNT_ID` / `CHANNEL_{id}_IG_ACCESS_TOKEN` (00식 id: 02~37)
  - `dry_run:true` 로 컨테이너 payload 미리보기 가능
- 스텁 경계 명시: `app/admin/ops/services/youtube_ig_bridge.py`

## n8n 자리 (placeholder)
- 템플릿: `n8n/WF-유튜브발행-인스타크로스포스트.template.json`
  - 노드 뼈대: 트리거 → 영상행 조회 → **[TODO] youTube 업로드(OAuth 크리덴셜 채널별)** → (Drive 공개) → **shortcrew /instagram/publish-reel 호출** → 결과 시트기록.
  - 운영자가 채널별 youTube 크리덴셜·시트 ID·`X-Ops-Token` 을 채워 현재 연결된 n8n 에 반영.

  `CHANNEL_{17,18,26}_VIDEO_SHEET_ID` 추가, `IG_BACKFILL_CHANNELS` 에 `17 18 26` 편입(총 18채널).

- **n8n 배선**: WF17·WF18·WF26 의 `YouTube 업로드` 뒤에 기존 13채널과 동일한 3노드 체인
  (`IG 공개권한(anyone)` → `IG 발행준비` → `IG 릴스 발행(/crosspost/reel)`)을 추가.
  `drive_video_id` 는 **`Stage3 시작`** 에서 읽는다(Stage2 노드 참조는 별도 실행이라 실패 — 기존 배선버그와 동일 함정).
  세 노드 모두 `onError: continueRegularOutput` 로 쇼츠 발행 플로우 보호.
  WF17·18 의 `Stage3 시작` 은 `등록설명`을 넘기지 않아, 발행준비 노드가 `단계 라우터` 의 `등록설명` → 대본 200자 순으로 폴백한다.
- **검증**: 26 채널 백필 1건 실발행 성공(reel `https://www.instagram.com/reel/Db3KbXCjHe1/`, 시트 `ig_media_id` 기록).
- **주의**: `.env` 변경은 `docker compose restart` 로 반영되지 않는다(env_file 은 컨테이너 생성 시 고정).
  **`docker compose up -d --build shortcrew`** 로 재생성해야 한다.
