## 바꾸는 곳 = n8n `WF-AUTO-SCRIPT` 노드 2개

### ① `Day Check + 채널 설정` 노드 → CHANNELS 의 WF24 교체
기존 `"WF24": {...Tech Pump...}` 를 아래로 **교체** (sheet·setting 은 그대로 유지):

```javascript
"WF24": {"wf": "24", "name": "안지아보안", "kr": "보안", "csvPrefix": "보안", "sheet": "1pfLL61oJd_eYzBjUQQKQzS3J-4TKoQqRQwNAPdW47ng", "setting": "tech-pump-v2", "pillars": ["홈/현관 보안", "차량·디지털 보안", "프라이버시·해킹 방지"], "commerce": true, "mallUrl": "https://shortcrew.co.kr/safety"},
```

### ② `프롬프트 구성` 노드 → 맨 위 `const ch = ...` 다음 줄에 분기 삽입
아래 블록을 **그대로 붙여넣기**. commerce 채널이면 안지아 커머스 프롬프트로 **조기 return**(출력 형식은 기존과 동일 → 다운스트림 무수정). 일반 채널이면 이 블록은 건너뛰고 기존 로직 그대로.

```javascript
// === [안지아 보안 커머스 분기] commerce 채널이면 별도 프롬프트로 조기 반환 ===
if (ch.commerce) {
  const _titles = $('기존 제목 로드').all().map(r => r.json['제목']).filter(Boolean);
  const _list = _titles.length ? _titles.map((t,i)=>`${i+1}. ${t}`).join('\n') : '(기존 대본 없음)';
  const _pillars = ch.pillars.join(' / ');
  const p = ch.product || {};
  const productBlock = p.name
    ? `[오늘의 해결책 상품] "${p.name}" — 핵심: ${p.points || ''}. 대본 3단계에서 이 상품을 '해결책'으로 자연스럽게 제시(노골적 광고 톤 금지).`
    : `[해결책 제시] 특정 브랜드 강요 없이 보안 카테고리(홈캠/스마트도어락/지문USB/블박 등)를 자연스럽게 언급하고, 구체 상품은 고정댓글·DM 링크로 유도.`;
  const systemPrompt = `당신은 보안 인플루언서 "안지아"의 유튜브 쇼츠 대본 작가입니다.

[페르소나] 순한 얼굴인데 보안 팩폭을 날리는 보안 덕후. 타겟 3050 남성. 톤=존댓말 해요체(~해요/~죠/~거든요), "이거 안 하면 진짜 털려요" 식 불안 자극 + 친근한 해결사. 반말 금지.

[분야 필라] ${_pillars}
[영상 길이] 60초 쇼츠 / 대본 350~400자

[대본 공식 — 커머스 전환형]
1) 훅(첫 6단어): 충격 사실·반전 질문으로 '내 얘기' 불안 자극. 인사말("여러분/오늘은") 금지.
2) 문제 각인: 왜 위험한지 구체 시나리오 1개.
3) ${productBlock}
4) 엔딩 퍼널(상시 구독멘트 금지): 유튜브용 "검증된 제품은 고정댓글 링크에 정리해놨어요." / 인스타용 "댓글에 '보안' 남겨주시면 검증된 링크 DM으로 보내드려요."

[금지] 과장광고·공포과잉, 수치비교("N배"), 단정표현("세계최초"), 반말. 팩트 기반·해요체 일관.

[기존 제목(중복 방지)]
${_list}

[출력 형식] 반드시 아래 JSON 배열로 30개 출력. JSON 외 텍스트 금지.
[
  {
    "no": 1,
    "카테고리": "필라명",
    "주제": "English Title | scene1 description | scene2 description | scene3 description | scene4 description | scene5 description | scene6 description",
    "제목": "한글 제목 (호기심 유발, 짧고 임팩트)",
    "대본": "(인사말 없이 첫 문장부터 불안 훅 ... 엔딩은 고정댓글/DM 퍼널 CTA, 구독멘트 없음)",
    "영상시간": "60s",
    "등록설명": "한글제목! #보안 #안지아 #shorts"
  }
]`;
  const userMessage = `위 규칙에 따라 "안지아(보안)" 채널의 새 대본 30개를 JSON 배열로 생성해주세요.`;
  return [{
    json: {
      channelConfig: ch,
      claudeBody: {
        model: "claude-sonnet-4-20250514",
        max_tokens: 16384,
        system: systemPrompt,
        messages: [{ role: "user", content: userMessage }]
      }
    }
  }];
}
// === 이하 기존 지식 채널 로직 그대로 ===
```

> `const ch.product` 는 (나중에) 브리지 P3 가 시트/HTTP 로 주입하면 채워진다. 지금은 없으면 제네릭 유도(else 분기)로 동작 → P3 없이도 테스트 가능.

## 테크펌프 영상 WF(채널별 영상생성+발행)에서 바꿀 것
대본 WF(WF-AUTO-SCRIPT)는 "보안 대본"만 만든다. 실제 영상의 **보이스·브랜딩은 채널별 영상 WF**
(북쇼츠 WF23 같은 4단계: 시트 → Fish Audio TTS → Remotion 렌더 → YouTube 업로드)에 있다.

> WF24 실측 결과 — 바꿀 곳은 딱 2곳(보이스는 이미 세련골프와 동일한 여성 보이스라 변경 불필요).

| 노드 | 현재 → 바꿀 값 | 우선도 |
|------|---------------|--------|
| **Fish Audio TTS** | `reference_id: 69f746f8b0764cf4a2beb60b1c5672c7` = **이미 세련골프 여성 보이스 → 변경 없음** ✅ | — |
| **Remotion 렌더링** | jsonBody 의 `channelName: "Tech Pump"` → `channelName: "안지아"` (영상에 박히는 브랜드명) | 🔴 |
| **YouTube 업로드** | options.tags / description 의 `테크펌프, TechPump, 기술, 테크, IT, 기술사, 실리콘밸리` → `안지아, 보안, 홈캠, CCTV, 도어락, 블랙박스, 보안팁` | 🔴 |
| Discord 알림 ×2 | 라벨 "Tech Pump" → "안지아" (내부 알림용, 미관) | 🟢 선택 |
| 업로드 대상 채널 | 테크펌프 YT 채널 그대로(OAuth 재활용) | 안 바꿈 |

## 주의: MVP 는 "얼굴 없는" 보이스 영상
기존 펌프 파이프라인은 **TTS 보이스 + 스톡/AI 비주얼**(faceless)이다. 따라서 이 테스트의 안지아 쇼츠도 **얼굴 없이** 나간다 — 페르소나의 "순한 외모 반전" 후크는 일단 빠진다.
- 지금 목적: **포맷·퍼널·전환이 먹히는지** 빠르게 검증.
- 얼굴(안지아 외모 반전)은 나중에 AI 아바타를 붙여 살린다. 프로필 이미지(inf-05.png)는 당분간 **쇼핑몰(/safety)·인스타 프로필**용.
