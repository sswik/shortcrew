# 테스트 결과 보고서

> 작성일: 2026-06-11(스냅샷) · 대상: `tests/` 자동화 + 수동 검증.
> "결과" 칸은 최신 실행 결과를 채워 넣는 자리. 시나리오 정의는 [테스트시나리오](테스트시나리오.md).

## 실행 방법

```bash
source .venv/bin/activate
python3 -m unittest tests.test_smoke -v
python3 -m unittest tests.test_shorts_sheet_matcher -v
```

## 결과 요약 (실행 시 기재)

| 스위트 | 케이스 수 | 통과 | 실패 | 비고 |
|--------|-----------|------|------|------|
| test_smoke | 10 | - | - | 인증 분기는 `ADMIN_PASSWORD` 좌우, 기본 채널 201 |
| test_shorts_sheet_matcher | 10 | - | - | URL 정규화·날짜·상품 매칭·스킵 조건 |

## 환경 의존 분기

- `ADMIN_PASSWORD` 미설정: ops/리뷰 경로 200/허용, 설정: 미인증 302.
- `google-key.json` 미존재: 시트 응답이 누락 env 키 안내.
- 쇼츠 자동화: 채널별 `SHORTS_AUTOMATION_ENABLED`·시트 컬럼 매핑 env 필요.

## 미커버 / 후속 권고

- 외부 API(쿠팡/IG/Gemini/YouTube) 실연동은 키 의존 → 수동/모킹.
- 쇼츠 리뷰 파이프라인 end-to-end 통합 테스트(시트→발행) 추가 여지.
- 리뷰 발행/중복 방지(`UNIQUE(influencer_slug, source_youtube_video_id)`) 회귀 테스트.
- 인스타 두-ID 하드닝 회귀 테스트(`docs/10`).
