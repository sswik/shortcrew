## 수동 검증 (브라우저)

- 백오피스 메뉴(상품·리뷰·인플루언서·시트·DM·로그) 동작.
- 리뷰 작성(Toast UI Editor) → 발행 → 공개 `/{slug}/review/{id}` 노출.
- AI 리뷰 초안(`/ai/review-draft`) 생성.
- 쇼츠-커머스 브리지 수동 실행: `POST /admin/api/ops/bridge/curate` → 상품 시트 적재(옵션 블로그/DM).
- 크로스포스트: `POST /admin/api/ops/crosspost/*` → 유튜브/IG 발행.
- 공개 몰 상품 클릭 → 쿠팡 이동 + 클릭 로그 적재.
