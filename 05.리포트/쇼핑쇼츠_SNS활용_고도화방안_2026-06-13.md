# 쇼핑쇼츠 SNS 활용 고도화 방안

> 작성일: 2026-06-13 · 작성: PM 겸 엔지니어 · 용도: 내부 전달(전략 제안서)
> 부제: 지식·쇼핑 쇼츠 콘텐츠를 **SNS 크로스포스트**와 **인플루언서 몰(○○픽)**로 확장해
> "콘텐츠는 도는데 쇼핑이 끊긴" 구간을 잇는 고도화 방안. **보안 세트(홈캠카오스↔안지아픽)를 첫 파일럿**으로 검증한다.

---

## 1. 배경·문제의식
- 우리는 이미 **지식·쇼핑 쇼츠를 자동 생성·발행**하는 파이프라인(대본→TTS→렌더→유튜브)을 운영 중이다.
- 그러나 **조회수는 나오는데 구매 전환이 끊긴다.** 쇼츠 시청자가 상품까지 도달하는 동선이 약하다.
- 동시에 **쇼츠 자산을 인스타 등 SNS로 충분히 확산하지 못하고**, 채널별 IG가 비어 있거나 수동 방치다.
- 고도화 목표: **(a) 쇼츠를 SNS로 자동 확산**하고 **(b) 영상 주제를 상품 큐레이션·블로그·DM으로 전환**해
  콘텐츠 한 편이 **인지 → 신뢰 → 구매**까지 흐르는 닫힌 루프를 만든다.

---

## 2. 고도화 핵심 전략 (3축)

| 축 | 내용 | 효과 |
|----|------|------|
| ① SNS 크로스포스트 | 생성 영상 1편을 유튜브 + **인스타 릴스로 자동 확산**(콘텐츠 브랜드 IG + 인플루언서 IG 양쪽) | 도달·노출 증대, 채널 자산화 |
| ② 주제기반 큐레이션 → 인플루언서 몰 | **영상 주제를 씨앗**으로 쿠팡 베스트/골드박스에서 Gemini가 1개 선정 → **인플루언서 몰(○○픽)에 등록** | 콘텐츠-상품 연관성↑, 전환 동선 생성 |
| ③ 블로그·DM 전환 | 선정 상품 1:1 매칭 **블로그(리뷰) 자동발행** + **댓글 키워드 자동DM** + 고정댓글 링크 | 신뢰 콘텐츠로 구매 마감 |

---

## 3. 운영 모델: 콘텐츠 브랜드 ↔ 인플루언서 몰 "세트"

쇼츠 콘텐츠 브랜드(조회수 담당)와 인플루언서 몰(전환 담당)을 **한 세트**로 묶는다.

| 콘텐츠 브랜드(지식쇼츠) | 인플루언서 몰(전환) | 백엔드 |
|------------------------|--------------------|--------|
| **홈캠카오스** `homecam.chaos` (보안) | **안지아픽** `jia.safety` (보안 인플루언서) | 홈캠카오스=short-mall / 안지아=short-crew |
| (확장) 기존 지식펌프 채널들 | (확장) 세련골프·세림테니스·한소율픽 등 | — |

- 원칙: **short-mall 콘텐츠 → short-mall IG, short-crew 콘텐츠 → short-crew IG.** 각자 자기 계정으로 발행.
- **큐레이션 결과는 인플루언서 몰(안지아픽, short-crew)에 적재**한다(전환 얼굴 일원화). ← 본 문서 확정 사항.
- 보안 세트로 모델을 검증한 뒤 다른 분야로 복제 확장한다(골프·테니스·쇼핑 등).

## 4. 표준 파이프라인 (목표 아키텍처)

```
            ┌──────────────────────────────────────────────┐
            │ n8n: 대본 생성 → 영상 생성(TTS·렌더) → Drive    │
            └───────────────┬──────────────────────────────┘
                            │ 생성 영상
        ┌───────────────────┼─────────────────────────────────┐
        ▼                                                       ▼
 [확산 A] 콘텐츠 브랜드 IG                           [확산 B] 인플루언서 IG
 홈캠카오스(short-mall)                              안지아픽(short-crew)  ← 발행코드 구현됨
        │
        │ 영상 "주제"를 씨앗으로
        ▼
 [큐레이션] 쿠팡 베스트/골드박스 후보 → Gemini 주제연관 1개 선정 (코드)
        │
        ▼  ← 안지아 몰(안지아픽)에 상품 등록  (※ 확정)
 [블로그] 선정 상품 1:1 → 리뷰 글 자동초안 → 발행
        │
        ▼
 [전환] 등록 상품 → 관리자 자동DM 세팅(수동) + 고정댓글 링크
        │
        ▼
 [추적] 클릭로그 → 딥링크(subId=shortcrew) → 구매 전환
```

---

## 5. 현 보유 자산 (이미 구현된 기반)

| 영역 | 구현 자산 | 상태 |
|------|-----------|------|
| 영상 생성 | n8n WF-AUTO-SCRIPT + 채널별 영상 WF(TTS·렌더·유튜브) | 운영중 |
| 안지아 IG 발행 | `publish-reel` 엔드포인트(컨테이너→폴링→발행), 공유토큰 인증, 채널105 | 구현(미배포) |
| 쿠팡 수집(P1) | `coupang.search_products`/`fetch_best_categories`/`fetch_goldbox` | 구현·검증 |
| 큐레이션(P2) | `gemini_curator.pick_product_for_topic`(주제연관 1개 선정) | 구현·검증 |
| **큐레이션 오케스트레이션(P3)** | `/bridge/curate` — 보안검색 후보풀→주제별 Gemini 선정→딥링크→안지아 몰 적재 | **구현·실API검증** |
| 블로그(리뷰) | `Review` 모델 + AI 초안 `/ai/review-draft` + 쇼츠시트 리뷰 자동화 | 구현 |
| 자동DM | `DmAutomation` + 댓글웹훅 자동DM(딥링크) | 구현 |
| 추적·딥링크 | `ClickLog` + `generate_deeplinks`(subId 고정 shortcrew) | 구현 |
| 인프라 | MySQL 전환, main.py 모듈 분해, 36테스트 통과 | 완료 |

> 요지: **부품의 70~80%가 이미 있다.** 고도화는 새 시스템을 짓는 게 아니라 **부품을 잇고 안지아 몰을 신설**하는 일이다.

## 6. 고도화 실행 항목 (신규로 메울 것)

1. **안지아픽 몰 신설** [신규]
   - shortcrew 로스터에 채널 105(`safety`) 추가(`roster/safety.py`), 공개 몰 `/safety`에 상품 노출.
   - 인플루언서 레코드(id=4, slug=safety)는 존재. **상품 공급원이 비어 있어** 큐레이션 연결 전까지 빈 몰.
2. **안지아 IG 발행 가동** [구현됨→배포]
   - 도커 재배포 + n8n 노드(Drive 공개→직링크→`publish-reel` HTTP) 연결.
3. **홈캠카오스 IG 발행** [미구현]
   - short-mall에 `publish-reel` 동일 포팅(권장) 또는 n8n 직접 호출. 홈캠카오스 영상→`homecam.chaos` 자동 발행.
4. **큐레이션 오케스트레이션(브리지)** [완료]
   - `POST /admin/api/ops/bridge/curate`: 보안 키워드 검색 후보풀 → 주제별 Gemini 선정 → 딥링크 → 안지아 몰 등록.
   - 실 API 검증: 후보풀 40개(전부 보안상품), 주제별 맞춤 선정·딥링크 정상. 남은 것은 n8n 스케줄 연결뿐.
5. **큐레이션 → 블로그 직결** [부분→완성]
   - 등록 상품을 AI 리뷰 초안으로 이어 안지아 몰에 블로그 자동발행(상품 1:1).

---

## 7. 본 문서 확정 사항
- **큐레이션 상품은 안지아 몰(안지아픽, short-crew)에 적재**한다(홈캠카오스 몰 아님). → 안지아픽 신설 필요.
- 큐레이션 코드(P1·P2)는 short-crew에 있으므로 **그대로 short-crew에서 오케스트레이션**(포팅 불필요).
- 인스타 발행은 **세트 양쪽 각자 계정**: 홈캠카오스=short-mall, 안지아=short-crew.

---

## 8. 로드맵 (우선순위)
1. [P0] 안지아 IG 발행 **배포 + n8n 연결** — 가장 가시적인 SNS 확산 데모.
2. [P0] **안지아픽 몰 신설**(로스터 105 + `/safety` 노출) — 전환 목적지 확보.
3. [완료] **큐레이션 오케스트레이션** — 주제→선정→안지아 몰 등록(`/bridge/curate`, 실검증). 남은 것은 n8n 스케줄.
4. [P1] **큐레이션→블로그 직결** — 상품 1:1 리뷰 자동발행.
5. [P1] 홈캠카오스 IG 발행 포팅 — 세트 양쪽 확산 완성.
6. [P2] 발행 후 고정댓글/DM 링크 자동 갱신 + 스케줄.

---

## 9. 기대 효과 (KPI 관점)
- **도달:** 영상 1편당 발행 채널 1→2~3개(유튜브+IG×세트)로 노출 면적 확대.
- **전환 동선:** 빈 몰 → 주제연관 큐레이션 상품 + 블로그 + DM으로 구매까지 경로 생성.
- **운영 효율:** 큐레이션·블로그·발행 자동화로 채널 추가의 한계비용↓(세트 복제로 분야 확장).
- **측정:** ClickLog·딥링크(subId=shortcrew)로 콘텐츠→클릭→구매 추적 가능.

---

## 10. 데모(검증) 시나리오
1. n8n에서 보안 주제 트리거 → 대본·영상 생성(Drive) 시연.
2. (배포 후) `publish-reel` dry-run → 토큰·채널105 연결 검증.
3. 실제 영상 1개 → 안지아 IG 릴스 발행, permalink 확인.
4. 같은 영상 주제로 큐레이션(P1·P2) 1건 → 선정 상품·사유 출력.
5. 선정 상품으로 AI 블로그 초안 1건 생성(상품 1:1) → 안지아 몰 노출안 보여주기.
6. 자동DM 규칙 1건 세팅 → 댓글 키워드 → 자동DM 흐름 설명.

> 미배포·미구현 항목은 dry-run/모형으로 "연결 검증"까지 보여주고 실가동은 후속 시연으로 분리.

## 11. 리스크·주의
- IG 토큰 만료(약 60일) → 발행 502, 재발급·교체 운영 필요.
- Drive `uc?export=download` 대용량 인터스티셜 가능성(릴스는 짧아 보통 무관, 대안: 공개 정적 경로).
- 보안: `OPS_API_TOKEN`·IG 토큰·`google-key.json`은 `.env`/키파일 전용(커밋 금지).
- **`.env`의 `GITHUB_TOKEN`(ghp_) 노출 상태 — 폐기·재발급 권장(미처리).**
- 미배포 코드(`publish-reel`)는 도커 재빌드 전까지 운영 미반영.
