# 중간 보고서 (n8n 변경분 검토 요청) — 2026-06-15

> 대상: 지도 선생님 검토용 · 작성: 운영 담당
> 요약: **지식쇼츠 '펌프' 채널 일부를 커머스 인플루언서로 전환**하고, **상품 큐레이션·인스타 발행 자동화 워크플로우**를 n8n에 추가했습니다.
> 서버(FastAPI) 코드는 모두 구현·배포 완료 상태이며, **아래 n8n 부분(직접 수정/신규 생성)을 검토받고 실행**하려 합니다. 이 문서만으로 전체 변경을 파악할 수 있도록 작성했습니다.

## 0. 한눈에 — 무엇을 했나

- **기존 펌프(지식쇼츠) 채널 3개**(테크/시네마/AI)를 각각 **커머스 인플루언서**(안지아/지서아/정세윤)로 전환.
- **기존 인플루언서 2개**(골프/테니스)도 동일한 큐레이션 방식으로 통일.
- 각 인플루언서마다: 영상(쇼츠) → 인스타 발행 + **영상 주제 기반 쿠팡 상품 큐레이션 → 몰 노출 + 블로그 + 자동DM** 까지 자동.
- 비즈니스 로직은 전부 서버 코드(엔드포인트)에 있고, **n8n은 스케줄·호출·풀칠만** 담당.

## 2. n8n에서 직접 수정/생성한 워크플로우 (검토 대상 ✅)

### 2-A. `WF-AUTO-SCRIPT (대본 자동 생성)` — **수정** (노드 1곳)

- **수정 노드:** `Day Check + 채널 설정` (코드 노드) 안의 `const CHANNELS = {…}`
- **변경 내용:** WF22 / WF24 / WF26 세 항목을 펌프 → 인플루언서로 교체.
  - **`sheet`·`setting` 값은 그대로 유지**(= 기존 유튜브 채널·영상 파이프라인 재활용), `name·kr·csvPrefix·pillars` 를 분야로 바꾸고 `commerce:true`·`mallUrl` 추가.
- **다운스트림(프롬프트 구성·Claude·Gemini 등)은 건드리지 않음** — 공통 프롬프트가 `pillars`만 보고 해당 분야 대본을 생성.

교체된 항목:

```js
"WF22": {"wf":"22","name":"Seoa Space","kr":"공간","csvPrefix":"공간","sheet":"13bK68-4PV4hFNzb7QxlKcuErG4V1O-_jYZtQ2K45GOg","setting":"cinema-pump-v2","pillars":["홈스타일링·방꾸미기","조명·무드 연출","공간활용·수납템"],"commerce":true,"mallUrl":"https://shortcrew.co.kr/space"}
"WF24": {"wf":"24","name":"안지아","kr":"보안","csvPrefix":"보안","sheet":"1pfLL61oJd_eYzBjUQQKQzS3J-4TKoQqRQwNAPdW47ng","setting":"tech-pump-v2","pillars":["홈/현관 보안","차량·디지털 보안","프라이버시·해킹 방지"],"commerce":true}
"WF26": {"wf":"26","name":"Seyun Science","kr":"테크","csvPrefix":"테크","sheet":"1C6XCSswy42DhTz3vkt-Kvr59DM6OuZKT_Yk9NQa6ZsY","setting":"ai-pump-v2","pillars":["데스크 셋업","가성비 가젯·주변기기","생산성 테크템"],"commerce":true,"mallUrl":"https://shortcrew.co.kr/science"}
```

**검토 포인트:** ① sheet/setting 유지가 맞는지(기존 채널 재활용 의도) ② pillars(분야 주제)가 적절한지.

### 2-B. 영상 워크플로우 3개 — **수정** (브랜딩, WF당 2곳 = 총 6곳)

대본 WF는 "주제"만 만들고, **영상의 채널명·유튜브 메타는 채널별 영상 WF**에 있어 각각 수정.

| 워크플로우                     | ① Remotion 렌더링 `channelName` | ② YouTube 업로드 `태그·설명` 키워드                                       |
| ------------------------------ | ---------------------------------- | ----------------------------------------------------------------------------- |
| `WF24 테크펌프→안지아`      | "Jia Safety"                       | 안지아, 보안, 홈캠, CCTV, 도어락, 블랙박스, 보안팁                            |
| `WF22 시네마→지서아(space)` | "Seoa Space"                       | 지서아, SeoaSpace, 공간, 방꾸미기, 홈스타일링, 인테리어, 무드등, 자취방꾸미기 |
| `WF26 AI→정세윤(science)`   | "Seyun Science"                    | 정세윤, SeyunScience, 테크, 데스크셋업, 가젯, IT꿀템, 전자제품, 생산성        |

> = 본문에서 말한 "description·tag 등 대여섯 군데" = **영상 WF 3개 × (channelName + 태그/설명) = 6곳**.
> (Fish Audio TTS 보이스, YouTube Localizations 노드는 변경하지 않음 — 그대로 동작.)
> **검토 포인트:** channelName 한글/영문 표기, 태그·설명 키워드 적절성.

### 2-C. `WF-인플루언서 큐레이션 (전채널 확장)` — **신규 생성**

- **흐름:** `스케줄(매일 08시) → 채널 목록(요일 분산 코드) → 오늘 채널 POST /bridge/curate → 디스코드 알림`
- **요일 분산 (Gemini 무료 한도 20/일 회피):** 매일 깨어나 **그 요일의 1채널만** 큐레이션 → 하루 호출 20 미만.
  - 월 105(안지아) / 화 110(정세윤) / 수 111(지서아) / 목 102(오세련) / 금 103(왕세림) / 토·일 휴무
- **서버가 채널별로:** 분야 키워드(trend_keywords)/영상주제로 쿠팡 검색 → AI(Gemini)가 주제연관 상품 1개 선정 → 딥링크(subId=shortcrew) → **큐레이션 시트 적재(게시중) + 상품 1:1 블로그 + 자동DM 규칙** 생성.
- **검토 포인트:** ① 요일 분산 배치 적절성 ② Google Sheets 자격증명 연결 ③ 대본 생성일과 겹치는 날 Gemini 합산 부하.

### 2-D. `WF-쇼츠 IG 크로스포스트 (영상시트→IG)` — **신규 생성**

- **흐름:** `스케줄 → 영상시트(시트1) 읽기 → 미발행분 필터 → Drive 공개 → POST /publish-reel → 시트 ig_url 표시 → 디스코드 알림`
- **미발행 필터:** `drive_video_id` 있고 `youtube_url` 있고 `ig_url` 빈칸인 행만 → 발행 후 `ig_url` 기록(중복 방지).
- **채널별 설정(복사해서 사용):** documentId(영상시트) + channel_id.
- **검토 포인트(중요):** 영상시트에 **전환 전 옛 영상(영화/AI 등)이 남아 있으면** 새 인플루언서 IG로 옛 콘텐츠가 발행될 수 있음 → **새 페르소나 영상 생성 후** 켜거나, 옛 행 `ig_url`을 채워 제외.

## 3. 서버(코드) 쪽 변경 — 이미 구현·배포 완료 (참고)

n8n이 호출하는 엔드포인트·로직은 모두 배포 상태입니다. (검토는 선택)

- `POST /admin/api/ops/bridge/curate` : 큐레이션 → 시트 적재 + 블로그 + 자동DM (인증 헤더 `X-Ops-Token`).
- `POST /admin/api/ops/instagram/publish-reel` : 드라이브 영상 → 인스타 릴스 (shortcrew + short-mall 양쪽).
- 공개 몰: Apps Script 없는 채널은 **서버가 구글시트(큐레이션 탭)를 직접 읽어** 상품 노출(게시중만).
- 딥링크: 입력을 클린 URL(`vp/products/{id}`)로 정규화해야 subId(shortcrew) 추적이 유지됨(검증 완료).
- 로스터 채널 신설: 110(정세윤)·111(지서아), 안지아 105. 102/103은 Apps Script→큐레이션 탭 직접읽기로 전환.
