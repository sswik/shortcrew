## 2. 이번 구간 핵심 결과물

- **큐레이션 1번 = 상품·블로그·자동DM** : `POST /admin/api/ops/bridge/curate` 가 채널 분야 키워드(or 영상 주제)로 쿠팡 검색 → Gemini 주제연관 1개 선정 → 딥링크 → **시트 적재(게시중) + 블로그(Review) 자동발행 + 자동DM 규칙 생성**까지 한 번에. 스케줄 주 1회.
- **인스타 자동 발행** : `POST /admin/api/ops/instagram/publish-reel`(컨테이너→폴링→발행 일괄). shortcrew(인플루언서) + short-mall(지식쇼츠) 양쪽 포팅. n8n 은 HTTP 1회.
- **쇼츠 IG 크로스포스트** : 영상시트(`drive_video_id`)의 기존 쇼츠를 그 채널 IG로 일괄 발행(중복방지 `ig_url`). 세련·세림·안지아 + 지식쇼츠 공통.
- **몰 상품 노출** : Apps Script 없는 채널은 서버가 시트를 직접 읽어 노출(소스=시트 일관, 게시중만).
- **딥링크 추적 복구** : 입력을 클린 URL(`vp/products/{id}`)로 정규화해야 subId(shortcrew)가 전파됨을 규명·수정·실측 검증. short-mall 과 동일 방식, 시트 K열에도 기록.
- **확장 구조** : 모든 엔드포인트가 `channel_id` 기반 → 채널 추가 = 로스터+.env+ n8n 채널목록 한 줄.
- **인프라** : SQLite→MySQL(crews) 전환, main.py(1431→62줄) 모듈 분해, 전체 34 단위테스트 통과.

## 3. 운영 모델

콘텐츠 브랜드(지식쇼츠, 조회수) ↔ 인플루언서 몰(○○픽, 전환)을 **세트**로 묶어 전 채널 복제.
- 보안 파일럿: 홈캠카오스(short-mall) ↔ 안지아픽(short-crew, `/safety`).
- 상품=시트(단일 소스), 블로그·트래킹=DB. 콘텐츠는 각자 프로젝트 IG로 발행.

## 4. 발견·결정 사항

- 큐레이션 상품은 **인플루언서 몰(시트)** 에 적재(DB 아님) — 기존 채널과 동일 구조 유지(사용자 결정).
- 미동작하던 **쇼츠 시트 자동발행 폐기**, 수동 리뷰 에디터·공개몰은 유지.
- 큐레이션이 자동화의 **단일 트리거** — 발행 시점이 아니라 큐레이션 시점에 상품·블로그·DM 생성.
- 두 프로젝트 동일 서비스계정(`sheetbot@sswik-2026`) → 시트 공유 자동.

## 5. 잔여 과제

- n8n: 큐레이션·크로스포스트 워크플로우 Import → 자격증명 연결 → 활성화(단계별 소량 테스트 후 스케줄).
- 각 채널 영상시트 `시트1`에 `ig_url` 컬럼 추가(크로스포스트 중복방지).
- (선택) 골프·테니스 상품쇼츠 발행 구조 전환 후 큐레이션 합류.
- 보안: `.env` `GITHUB_TOKEN` 폐기 / IG 토큰 만료(60일) 교체.
