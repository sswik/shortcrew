# 정보 구조도 (IA)

> shortcrew 화면·URL 위계. (근거: `main.py` 라우트, 템플릿)

## 사이트맵

```
공개 (인증 없음)
├── /                              인플루언서 홈
├── /about                         소개
├── /privacy                       개인정보처리방침
├── /{name_slug}                   독립몰 허브 (상품 탭)
│   ├── /{name_slug}/introduce     소개 탭
│   ├── /{name_slug}/review        리뷰 목록 탭
│   └── /{name_slug}/review/{id}   리뷰 상세
└── /shop/{...}, /reviews/{...}    (레거시 → 301)

백오피스 (/admin, 세션 인증)
├── /admin/login · logout · dashboard
├── /admin/products                상품 관리
├── /admin/reviews                 리뷰 목록
│   ├── /admin/reviews/new         새 리뷰(Editor)
│   ├── /admin/reviews/{id}        상세(Viewer)
│   └── /admin/reviews/{id}/edit   수정
├── /admin/influencers             인플루언서 집계
│   └── /admin/influencers/{slug}/edit
├── /admin/sheets                  시트 안내
└── /admin/logs                    클릭 로그

API/연동
├── /api/mall-products · /api/click
├── /admin/api/ops/*               (channels·coupang·naver·sheets·ai·mall·shorts-review·dm)
└── /webhooks/instagram
```

## 콘텐츠 분류

| 분류 | 소스 | 설명 |
|------|------|------|
| 인플루언서 메타 | `influencers`(MySQL) | 표시명·SNS·테마·프로필 메타 |
| 공개 상품 | Google Sheets(Apps Script) | 노출 상품 진실 소스 |
| 등록 상품 | `products`(MySQL) | 백오피스 등록·집계 |
| **리뷰** | `reviews`(MySQL) | 수동/AI/쇼츠 자동 발행 |
| 클릭 | `click_logs`(MySQL) | 전환 추적 |
| DM 규칙 | `dm_automations`(MySQL) | 채널별 자동 DM |
| 쇼츠 계획 | Google Sheets(채널별 SHORTS_*) | 리뷰 자동 발행 트리거 |
| 접속 로그 | `logs/access_*.txt` | 서버 원본 로그 |
