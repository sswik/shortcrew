# 마켓 리서치

> 코드에 직접 근거가 없는 시장 분석 영역. **추정·전제 위주 골격**이며, 수치·출처는 실제 조사로 채워야 한다.

## 시장 정의

- 도메인: **인플루언서 커머스(쿠팡 파트너스) × 숏폼(쇼츠) 콘텐츠 전환**.
- 대상: 골프/테니스/쇼핑 등 분야별 인플루언서가 쇼츠·리뷰로 트래픽을 수익화하는 시장.

## 경쟁/대안 유형 (정성)

| 유형 | 설명 | shortcrew 차별점 |
|------|------|------------------|
| 링크인바이오 | 프로필 링크 모음 | 상품 허브 + **리뷰 발행** + 클릭 로깅 통합 |
| 블로그/리뷰 플랫폼 | 수동 리뷰 작성 | **AI 초안 + 쇼츠 시트 트리거 자동 발행** |
| 개별 랜딩 제작 | 인플루언서별 수작업 | 슬러그 라우팅 + 로스터 코드 확장 |

## 자사 강점 (운영 구조 기반)

- 쇼츠 발행과 리뷰 발행을 시트로 동기화하는 **자동 파이프라인**.
- 비개발자도 시트로 상품·쇼츠 계획 운영.
- 분야별 채널 로스터(골프/테니스/쇼핑) 코드화로 확장 비용 낮음.
