## 기능 상세 (추가/차별 기능 위주)

### F-003. 공개 리뷰 페이지

| 항목 | 내용 |
|------|------|
| 입력 | `GET /{slug}/review`, `/{slug}/review/{id}` |
| 처리 | `reviews` 조회 → `review_html.py`로 본문 안전 렌더 → 연결 상품 딥링크 노출 |
| 출력 | 리뷰 목록/상세 HTML |
| 예외 | 미존재 리뷰 404, 레거시 `/reviews/...` 301 |
| 관련 | `client/review_list.html`, `review_detail.html` |

### F-004. 백오피스 리뷰 CRUD

| 항목 | 내용 |
|------|------|
| 입력 | `/admin/reviews`(목록), `/new`, `POST /admin/reviews`, `/{id}/edit` |
| 처리 | Toast UI Editor로 작성 → 저장(`reviews`) → 상품 연결(`product-options`) |
| 출력 | 리뷰 관리 HTML, Viewer 상세 |
| 예외 | 인증 필요, `UNIQUE(influencer_slug, source_youtube_video_id)` 중복 방지 |
| 관련 | `admin/reviews*.html`, `admin-review-editor/viewer.js`, `review_publish_service.py` |

### F-005. AI 리뷰 초안

| 항목 | 내용 |
|------|------|
| 입력 | `POST /ai/review-draft` (상품/영상 컨텍스트) |
| 처리 | Gemini로 리뷰 초안 생성(`gemini_review_draft.py`) |
| 출력 | 에디터에 채워지는 초안 텍스트 |
| 예외 | Gemini 키 미설정/실패 폴백 |
| 관련 | `admin-review-ai.js` |

### F-006. 쇼츠 시트 트리거 리뷰 자동화 ★핵심 추가

| 항목 | 내용 |
|------|------|
| 입력 | 쇼츠 발행 계획 시트(채널별 `CHANNEL_NN_SHORTS_*`), 트리거: 크론(06:00 KST) 또는 `POST /shorts-review/run` |
| 처리 | 계획 시트 읽기 → 발행일·상태 조건 매칭(`shorts_sheet_matcher.py`) → 유튜브 트랜스크립트 → Gemini 리뷰 생성(`gemini_review_from_sheet_shorts.py`) → 상품 자동 연결(`shorts_product_autolink.py`) → 발행(`review_publish_service.py`) |
| 출력 | `reviews` 자동 생성·발행, 시트 상태 갱신 |
| 예외 | 상품 매칭 실패 시 스킵, 발행일이 기준일과 다르면 스킵, 중복 영상 스킵 |
| 관련 | `scripts/run_shorts_sheet_reviews.py`, `deploy/shorts-review-cron.crontab`, `shorts_review_pipeline.py`, `shorts_review_config.py`, `docs/06`, `docs/07` |

### F-011. 인스타 댓글→자동 DM (두-ID 하드닝)

| 항목 | 내용 |
|------|------|
| 입력 | `POST /webhooks/instagram` + `/dm/rules` |
| 처리 | 규칙 매칭 → 공개 답글(랜덤 변형) + DM 딥링크. ACCOUNT_ID(네이티브)+APP_SCOPED_ID 2종으로 **두-ID 루프 방지** |
| 출력 | 답글·DM 발송 |
| 예외 | 비활성 규칙 스킵, follower_only |
| 관련 | `app/webhooks/instagram.py`, `routes/dm.py`, `docs/09`, `docs/10` |
