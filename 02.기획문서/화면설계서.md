## 주요 레이아웃

### SCR-003 독립몰 허브 (`shop.html`)
```
┌──────────────────────────────┐
│ 헤더(인플루언서명/SNS)              │
├──────────────────────────────┤
│ [상품] [리뷰] [소개]  ← 탭(shop-tabs.js) │
├──────────────────────────────┤
│ 상품 그리드(shop-products.js)        │
│  클릭 → /api/click → 쿠팡 딥링크      │
└──────────────────────────────┘
* 인플루언서 테마(시안/앰버) 동적 적용
```

### SCR-105 리뷰 작성/수정 (`reviews_form.html`)
```
┌──────────────────────────────┐
│ 제목 / 인플루언서·상품 연결           │
├──────────────────────────────┤
│ [AI 초안 생성]  ← admin-review-ai.js │
│ ┌──────────────────────────┐ │
│ │ Toast UI Editor (마크다운)    │ │  ← admin-review-editor.js
│ └──────────────────────────┘ │
├──────────────────────────────┤
│ [저장/발행]                       │
└──────────────────────────────┘
```

### SCR-006 리뷰 상세 (`review_detail.html`)
```
┌──────────────────────────────┐
│ 리뷰 제목 / 작성일                  │
├──────────────────────────────┤
│ 본문(review_html.py 렌더)          │
├──────────────────────────────┤
│ 연결 상품 카드 → 쿠팡 딥링크(CTA 앰버) │
└──────────────────────────────┘
```
