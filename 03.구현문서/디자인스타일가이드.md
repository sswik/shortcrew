# 디자인 스타일 가이드

> shortcrew UI 스타일 규약(ShortCrew V2). (근거: `app/client/mall_theme.py`, `app/admin/templates/_admin_tailwind_config.html`, 템플릿/JS)

## 브랜드 테마 (ShortCrew V2)

| 토큰 | 값 | 용도 |
|------|-----|------|
| background | `#121212` | 다크 배경 |
| card | `#1E1E1E` | 카드 |
| surface-muted | `#262626` | 보조 면 |
| border | `#2E2E2E` | 구분선 |
| accent (cyan) | `#00C2D1` | 시안 강조(`accentDark #0098A3`) |
| **CTA (amber)** | `#FFB800` | 구매/행동 버튼(`ctaHover #E6A600`) |
| textMain | `#FFFFFF` | 본문 |
| textSub | `#A3A3A3` | 보조 텍스트 |

- 공개 몰 테마는 인플루언서별 `mall_theme_json`으로 override(없으면 위 기본값).
- CSS 변수 주입: `--cyan-main`, `--cyan-dark`, `--surface-muted` 등(`mall_theme.py`).

## 두 스타일 시스템

| 구분 | 공개(client) | 백오피스(admin) |
|------|--------------|-----------------|
| 방식 | CSS 변수 기반 커스텀 CSS(`static/css/style.css`) | Tailwind(CDN) + `_admin_tailwind_config.html` |
| 강조 | 인플루언서 동적 테마 | **공개와 통일된 시안(`#00c2d1`) + 앰버(`#ffb800`)** |
| 팔레트 | 다크 121212 계열 | primary 50~900(시안), base/card/muted/border, amber |

> 백오피스도 공개 UI 시안 계열로 통일(`_admin_tailwind_config.html` 주석 명시).

## 리치 텍스트 (리뷰)

- 작성: **Toast UI Editor**(`admin-review-editor.js`), 열람: **Toast UI Viewer**(`admin-review-viewer.js`).
- AI 초안: `admin-review-ai.js` → `POST /ai/review-draft`.
- 공개 렌더: `app/client/review_html.py`가 마크다운/HTML을 안전 변환.

## 정적 자산

- `/static` → `static/{css,js,images}/`.
- 인플루언서 이미지 `static/images/influencers/`, 브랜드 `static/images/brand/`.
- 이미지 썸네일은 Cloudflare 워커(`workers/coupang-image-proxy`, `image.shortcrew.co.kr`)로 프록시.
