# 인프라 아키텍처

> shortcrew 인프라 구성. (근거: `Dockerfile`, `docker-compose.yml`, `.env.example`, `README.md`)

## 시스템 구성도

```
[방문자 브라우저]
      │  https://shortcrew.co.kr
      ▼
[Cloudflare Zero Trust Tunnel]  (cloudflared, network_mode: host, profile tunnel)
      │  http://127.0.0.1:8028
      ▼
[shortcrew 컨테이너]  (uvicorn main:app)
      ├── MySQL (mysql-server:3306, DB crews, ejlab_global_net)
      ├── logs/access_*.txt (볼륨)
      ├── google-key.json (ro 볼륨)
      └── [인앱 스케줄러] 큐레이션·스크립트·IG백필·IG토큰갱신 (asyncio, on_event startup)
      │
   (외부 연동, httpx)
      ├── Google Sheets / Apps Script (상품·쇼츠 계획 시트)
      ├── 쿠팡 파트너스 (subId=shortcrew, lptag)
      ├── Instagram Graph API (웹훅·DM)
      ├── 네이버 데이터랩 / Google Gemini / YouTube Data API
      └── [이미지 프록시] workers/coupang-image-proxy (Cloudflare Worker, image.shortcrew.co.kr)
```

## 컨테이너 구성 (compose 2서비스)

| 서비스 | 컨테이너 | 포트/네트워크 | profile | 용도 |
|--------|----------|---------------|---------|------|
| shortcrew | `shortcrew` | `127.0.0.1:8028:8028` | (기본) | FastAPI 앱 |
| cloudflared | `shortcrew-cloudflared` | `network_mode: host` | `tunnel` | 공개 터널 |

- 이미지: 단일 `Dockerfile`.
- COPY: `main.py`, `models.py`, `static/`, `app/`, `scripts/`.

> **폐기**: 과거 `shorts-review-cron`(supercronic, 매일 06:00 KST `run_shorts_sheet_reviews.py`) 및 쇼츠 시트 자동발행은 제거됨. 별도 크론 컨테이너 없음.

## 인앱 스케줄러 (asyncio, n8n 비의존)

앱 기동 시(`main.py` `on_event("startup")`) 아래 백그라운드 루프가 뜬다.

| 스케줄러 | 서비스 | 역할 |
|----------|--------|------|
| 큐레이션 | `curation_scheduler.py` | 지정 시각(KST, `CURATION_SCHEDULER_HOUR`)에 커머스 채널 1개 로테이션 큐레이션 → 상품 시트 적재 |
| 스크립트 | `scripts_scheduler.py` | 예약 쇼츠 대본/발행 큐 처리 |
| IG 백필 | `ig_backfill_scheduler.py` | 과거 영상 → IG 릴스 백필(워밍업 캡) |
| IG 토큰 갱신 | `ig_token_refresh.py` | IG 장기 토큰 40일 주기 자동 갱신 |

- 수동 트리거는 각 Ops API(`/admin/api/ops/bridge/*`, `/curation/*`, `/crosspost/*` 등)로 제공.

## 배포 절차

```bash
docker compose up -d --build                         # 앱만
docker compose --profile tunnel up -d --build        # + 공개 터널
curl http://127.0.0.1:8028/health
```

## 환경 변수 카테고리

| 카테고리 | 키(예) |
|----------|--------|
| 앱/공개 | `APP_NAME`, `APP_HOST`, `APP_PORT`, `APP_DOMAIN`, `PUBLIC_SITE_URL`, `DATABASE_URL`, `CLOUDFLARE_TUNNEL_TOKEN` |
| 백오피스 | `ADMIN_EMAIL`, `ADMIN_PASSWORD` |
| 채널(반복) | `CHANNEL_NN_FILE_ID/_TAB/_HISTORY_TAB/_PRODUCT_DELIVERY_WEBAPP_URL/_MALL_PUMP_SLUG/_MALL_PRODUCTS_API_URL/_MALL_PRODUCTS_CHANNEL_PARAM` (NN=00식 02~37) |
| ~~쇼츠 자동화(반복)~~ | **폐기**. `CHANNEL_NN_SHORTS_*` 키는 레거시 잔존(쇼츠 시트 자동발행 크론 제거로 미사용) |
| 쿠팡 | `COUPANG_ACCESS_KEY/_SECRET_KEY/_PARTNERS_LPTAG/_IMAGE_WORKER_BASE` |
| 네이버/AI/영상 | `NAVER_CLIENT_ID/_SECRET`, `GOOGLE_GEMINI_KEY`, `YOUTUBE_API_KEY` |
| 클릭 | `MALL_CLICK_LOG_AUTH_TOKEN` |
| 인스타 | `IG_APP_ID/_APP_SECRET/_WEBHOOK_VERIFY_TOKEN/_GRAPH_API_VERSION` + 채널별 `CHANNEL_NN_IG_*` |

> 인스타 댓글→DM은 **shortcrew 전용 Meta 앱**으로 운영(short-mall과 분리).
