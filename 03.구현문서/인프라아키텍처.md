# 인프라 아키텍처

> shortcrew 인프라 구성. (근거: `Dockerfile`, `docker-compose.yml`, `deploy/shorts-review-cron.crontab`, `.env.example`, `README.md`)

## 시스템 구성도

```
[방문자 브라우저]
      │  https://shortcrew.co.kr
      ▼
[Cloudflare Zero Trust Tunnel]  (cloudflared, network_mode: host, profile tunnel)
      │  http://127.0.0.1:8028
      ▼
[shortcrew 컨테이너]  (uvicorn main:app)
      ├── SQLite (database.db, 볼륨)
      ├── logs/access_*.txt (볼륨)
      └── google-key.json (ro 볼륨)
      │
[shorts-review-cron 컨테이너]  (supercronic, profile shorts-cron, 동일 이미지)
      └── 매일 06:00 KST → scripts/run_shorts_sheet_reviews.py
      │
   (외부 연동, httpx)
      ├── Google Sheets / Apps Script (상품·쇼츠 계획 시트)
      ├── 쿠팡 파트너스 (subId=shortcrew, lptag)
      ├── Instagram Graph API (웹훅·DM)
      ├── 네이버 데이터랩 / Google Gemini / YouTube Data API
      └── [이미지 프록시] workers/coupang-image-proxy (Cloudflare Worker, image.shortcrew.co.kr)
```

## 컨테이너 구성 (compose 3서비스)

| 서비스 | 컨테이너 | 포트/네트워크 | profile | 용도 |
|--------|----------|---------------|---------|------|
| shortcrew | `shortcrew` | `127.0.0.1:8028:8028` | (기본) | FastAPI 앱 |
| shorts-review-cron | `shortcrew-shorts-review-cron` | - | `shorts-cron` | supercronic 일일 리뷰 자동 발행 |
| cloudflared | `shortcrew-cloudflared` | `network_mode: host` | `tunnel` | 공개 터널 |

- 이미지: 동일 `Dockerfile`. supercronic를 이미지에 설치(아키텍처 amd64/arm64 분기).
- COPY: `main.py`, `models.py`, `static/`, `app/`, `scripts/`, `deploy/shorts-review-cron.crontab`.

## 크론 (쇼츠 리뷰 자동 발행)

```cron
# deploy/shorts-review-cron.crontab  (컨테이너 TZ=Asia/Seoul)
0 6 * * * /usr/local/bin/python /app/scripts/run_shorts_sheet_reviews.py
```

- 쇼츠 발행 계획 시트를 읽어 조건 충족 행에 대해 리뷰를 자동 생성·발행.
- 수동 트리거: `POST /admin/api/ops/shorts-review/run`.

## 배포 절차

```bash
docker compose up -d --build                         # 앱만
docker compose --profile shorts-cron up -d --build   # + 쇼츠 크론
docker compose --profile tunnel up -d --build        # + 공개 터널
curl http://127.0.0.1:8028/health
```
