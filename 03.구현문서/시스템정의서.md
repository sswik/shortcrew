# 시스템 정의서

> shortcrew의 기술 스택·모듈·인터페이스 규약. (근거: `main.py`, `models.py`, `app/`, `requirements.txt`, `Dockerfile`)

## 기술 스택

| 영역 | 기술 | 비고 |
|------|------|------|
| 언어/런타임 | **Python 3.12** | `python:3.12-slim` |
| 웹 | **FastAPI** | 단일 앱 `main:app` |
| ASGI | **uvicorn** | 포트 **8028** |
| ORM/DB | **SQLAlchemy 2.0 + MySQL** | `mysql-server:3306` DB `crews`. `.env` 의 `DATABASE_URL` 필수 |
| 템플릿 | **Jinja2** | client/admin 2개 디렉터리 |
| 리치 에디터 | **Toast UI Editor/Viewer** | 백오피스 리뷰 작성/열람 |
| HTTP | **httpx** | 외부 API |
| 외부 SDK | gspread+google-auth(시트), google-genai(Gemini), pandas, PyJWT, cryptography, Pillow | `requirements.txt` |
| 스케줄러 | **인앱 asyncio** | `on_event("startup")` 백그라운드 루프(큐레이션·스크립트·IG백필·IG토큰갱신). supercronic/외부 크론 없음 |
| 배포 | Docker compose 2서비스 + Cloudflare Tunnel | |

## 인터페이스 규약

- 공개 라우트: HTML 또는 JSON(`/api/mall-products`, `/api/click`), 인증 없음
- 백오피스 HTML: `/admin/*`, `ADMIN_PASSWORD` 설정 시 세션 인증
- Ops JSON API: prefix `/admin/api/ops`
- 웹훅: `/webhooks/instagram` 공개, `IG_WEBHOOK_VERIFY_TOKEN` 검증
- 쇼츠-커머스 브리지/큐레이션: `POST /bridge/*`·`/curation/*`(수동) + 인앱 큐레이션 스케줄러(KST, `CURATION_SCHEDULER_HOUR`). 구 쇼츠 시트 자동발행 크론(06:00)은 폐기.
- 크로스포스트/IG: `POST /crosspost/*`·`/instagram/*` + IG 백필·토큰갱신 스케줄러
- 상품 소스: 시트(Apps Script JSON), 서버 120s 캐시

## 에러 처리 규약

- FastAPI 기본 예외 → `{"detail": ...}`
- 미인증 백오피스 접근 → `/admin/login` 302
- 레거시 `/shop/...`, `/reviews/...` → 301
- 외부 API 실패 → 빈/폴백 응답
